# Build Hooks and Packaging Assets

Electron Builder resources and macOS packaging hooks. This directory is operational packaging code, not app runtime code.

## Files

| File                             | Role                                                                                                              |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `after-pack.cjs`                 | Post-package optimization hook: strips binaries and locales on **darwin** only; no-ops for win32/linux. |
| `entitlements.mac.plist`         | Main app entitlements for macOS signing.                                                                          |
| `entitlements.mac.inherit.plist` | Inherited entitlements for helpers/frameworks.                                                                    |
| `icon.icns`                      | macOS app icon generated by `scripts/generate-calendar-tray-icons.mjs` (iconutil).                                |
| `icon.ico`                       | Windows app icon (multi-size) generated by the same script via sharp (any OS).                                    |

## Where to Look

| Task                     | Location                                      | Notes                                                                             |
| ------------------------ | --------------------------------------------- | --------------------------------------------------------------------------------- |
| Change packaged file set | `../electron-builder.yml`                     | `files`, `asarUnpack`, target arches.                                             |
| Shrink app bundle        | `after-pack.cjs`                              | Darwin only; both arm64 and x64 macOS builds. Skips when `electronPlatformName !== "darwin"`. |
| Configure notarization   | `../electron-builder.yml`                     | Electron Builder owns app notarization with `mac.notarize: true`. |
| Change app icon          | `../scripts/generate-calendar-tray-icons.mjs` | Regenerates `icon.icns` and tray PNGs.                                            |
| Local DMG behavior       | `../build-macOS-dmg.sh`                       | Apple Silicon helper with ad-hoc re-sign workaround.                              |

## Packaging Rules

- Only `afterPack` is wired from root `electron-builder.yml`.
- `after-pack.cjs` assumes macOS `.app` layout and Electron Framework helper names; it must return early for non-darwin platforms.
- Electron Builder signs and notarizes the app before DMG/ZIP containers are created. The official tag workflow preflights `CSC_LINK`, `CSC_KEY_PASSWORD`, `APPLE_ID`, `APPLE_TEAM_ID`, and `APPLE_APP_SPECIFIC_PASSWORD`; local packaging may omit them.
- Keep `allow-jit`, Calendar, and Apple Events grants. Do not add unsigned executable-memory or disabled-library-validation entitlements.
- Keep Swift source unpacking in root `electron-builder.yml`; `swiftc` cannot read from ASAR.

## Anti-Patterns

- Do not make hooks depend on TypeScript build output paths except packaged `.app` paths.
- Do not remove `en.lproj` when pruning locales.
- Do not add a custom `afterSign` notarization hook; Electron Builder is the sole notarization owner.
- Do not edit generated `icon.icns` by hand; regenerate it from the script.
