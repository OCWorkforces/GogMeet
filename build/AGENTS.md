# Build Hooks and Packaging Assets

Electron Builder resources and macOS packaging hooks. This directory is operational packaging code, not app runtime code.

## Files

| File                             | Role                                                                                                              |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `after-pack.cjs`                 | Post-package macOS optimization hook: strips binaries, removes non-English Electron locales, reports bundle size. |
| `notarize.cjs`                   | **afterSign** hook: notarytool notarize + `xcrun stapler staple` + validate. Sole notarization owner.             |
| `entitlements.mac.plist`         | Main app entitlements for macOS signing.                                                                          |
| `entitlements.mac.inherit.plist` | Inherited entitlements for helpers/frameworks.                                                                    |
| `icon.icns`                      | App icon generated by `scripts/generate-calendar-tray-icons.mjs`.                                                 |

## Where to Look

| Task                     | Location                                      | Notes                                                                                         |
| ------------------------ | --------------------------------------------- | --------------------------------------------------------------------------------------------- |
| Change packaged file set | `../electron-builder.yml`                     | `files`, `asarUnpack`, target arches, `publish` for electron-updater.                         |
| Shrink app bundle        | `after-pack.cjs`                              | Runs for both arm64 and x64 macOS builds.                                                     |
| Configure notarization   | `notarize.cjs` + `electron-builder.yml`       | Custom afterSign owns notarize+staple; keep `mac.notarize: false` (no dual path).             |
| Change app icon          | `../scripts/generate-calendar-tray-icons.mjs` | Regenerates `icon.icns` and tray PNGs.                                                        |
| Local DMG behavior       | `../build-macOS-dmg.sh`                       | Apple Silicon helper with ad-hoc re-sign workaround.                                          |

## Packaging Rules

- `afterPack` optimizes the bundle; `afterSign` notarizes and staples the `.app` before DMG/ZIP.
- `hardenedRuntime: true` in `electron-builder.yml`.
- Env for official notarize: `APPLE_ID`, `APPLE_TEAM_ID`, `APPLE_APP_SPECIFIC_PASSWORD` (legacy `APPLE_APP_PASSWORD` accepted with deprecation warning).
- Local packaging without secrets skips notarize and logs clearly.
- Keep `allow-jit`, Calendar, and Apple Events grants. `allow-unsigned-executable-memory` remains for Electron 43 + hardened runtime unless package smoke proves it can be removed.
- Keep Swift source unpacking in root `electron-builder.yml`; `swiftc` cannot read from ASAR.
- Official verification (`bun run verify:macos-release`) requires a stapled app (`stapler validate`).

## Anti-Patterns

- Do not make hooks depend on TypeScript build output paths except packaged `.app` paths.
- Do not remove `en.lproj` when pruning locales.
- Do not enable electron-builder `mac.notarize: true` while `afterSign: notarize.cjs` is wired (dual notarize).
- Do not edit generated `icon.icns` by hand; regenerate it from the script.
